# Cálculo de estructuras navales · notebooks académicos

**Tipo:** académico

**Estado:** archivado — última actualización pública en mayo de 2025

## Qué demuestra este repositorio

Reúne notebooks de Python utilizados para explorar el modelado y la visualización de estructuras 2D y 3D: celosías, cargas, apoyos, desplazamientos y modelos simplificados de una grúa naval. Los ejercicios emplean NumPy y Matplotlib e incluyen aproximaciones académicas de análisis estructural, pandeo, respuesta dinámica y fatiga.

El repositorio permite revisar el código, las hipótesis y las visualizaciones producidas por cada notebook.

## Qué no demuestra

- No es software de ingeniería validado ni una herramienta oficial de la FNB/UPC.
- Los resultados son simulaciones académicas y no sustituyen cálculos, ensayos ni revisiones profesionales.
- Las etiquetas internas como «cumple», «adecuada» o «profesional» que puedan aparecer en versiones de los notebooks forman parte del ejercicio y **no constituyen certificación ni conformidad** con DNV, ABS u otra entidad.
- No se ha documentado una verificación independiente, una campaña de ensayos ni un uso en un proyecto construido.

## Contenido

- `Figura_en_2D_con_apoyo_movil*.ipynb`: visualización y cálculo de una celosía 2D con apoyo móvil.
- `Figuras_con_mas_de_fuerza.ipynb`: ejercicio de cercha 2D con varias cargas y visualización de la deformada.
- `Trabajo_final_EF_FNB.ipynb`: exploración académica de un modelo de grúa naval.
- `Trabajo_final_EF_FNB_3D*.ipynb`: iteraciones 3D del mismo ejercicio con análisis y visualizaciones adicionales.

## Uso responsable

Cada notebook debe leerse junto con sus hipótesis y unidades. Antes de reutilizar una fórmula o un resultado hay que comprobar el modelo, las condiciones de contorno, las propiedades de material, las cargas y la convergencia. Cualquier aplicación real requiere revisión por una persona profesional competente y las validaciones que correspondan.
